# Ketcher React Native

React Native integration for Ketcher chemical structure editor.

## Features

- Touch interface for drawing chemical structures
- WebView integration of Ketcher editor
- Compatible with iOS and iPad devices
- Expo-based implementation for easy development and testing

## Getting Started

```bash
# Install dependencies
npm install

# Start the development server
npx expo start
```

## Usage

The app includes a tab-based navigation with a dedicated Ketcher tab that loads the Ketcher editor in a WebView.
